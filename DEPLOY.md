# Инструкция по развертыванию приложения (Деплой)

Поскольку наше приложение использует локальную базу данных SQLite и сохраняет загруженные картинки прямо в файловую систему сервера, идеальным решением будет **VPS (Виртуальный выделенный сервер)** с поддержкой **Docker**.

## 🚀 Самый быстрый способ (Timeweb Cloud / Beget / Selectel)

1. Зарегистрируйтесь на любом облачном хостинге (например, [Timeweb Cloud](https://timeweb.cloud/) или [Beget](https://beget.com/ru)).
2. Создайте новый сервер (VPS). 
   - Операционная система: **Ubuntu 22.04** (или новее).
   - ПО: Выберите предустановленный **Docker** (в маркетплейсе хостинга), чтобы не ставить его вручную.
   - Минимального тарифа (~200 руб/мес) хватит с головой.
3. Подключитесь к серверу по SSH.
4. Скопируйте все файлы вашего проекта на сервер (можно через GitHub или SFTP).
5. На сервере, находясь в папке проекта (там, где лежит файл `docker-compose.yml`), выполните команду:
   ```bash
   docker compose up --build -d
   ```

**Всё! 🎉** 
Ваше приложение (и фронтенд, и бекенд) соберется в один легковесный контейнер и будет доступно прямо по IP-адресу вашего сервера на стандартном 80 порту. 

> *Все загруженные вами картинки и база данных будут сохранены в папке сервера благодаря томам (volumes) в docker-compose, поэтому при перезагрузке сервера ничего не пропадет!*

## 🔧 Альтернатива: Amvera Cloud
Если вы не хотите возиться с консолью Linux, вы можете использовать платформу [Amvera.ru](https://amvera.ru) (российский аналог Heroku). 
У них есть поддержка Docker и **постоянного хранилища (Persistent Storage)**. Просто привяжите свой GitHub репозиторий, укажите путь к `Dockerfile`, а в настройках Amvera создайте постоянное хранилище и примонтируйте его к папкам `/app/backend/dev.db` и `/app/backend/uploads`.
